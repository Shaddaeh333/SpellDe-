# SpellDE

A German spelling game for learners, with English hints to help you understand each word.

**Play it now:** https://spellde.netlify.app

## About
SpellDE is the German-vocabulary version of my first game, Link-It Kids. It keeps the same mechanics and scoring, with a fully German interface and English hints for clarity.

## Features
- 90 German words, each with an emoji and an English hint
- Three levels: Easy, Medium and Hard (by word length)
- Three lives, a score counter and sound effects
- Works on phones and in the browser

## How to access it
Open the link above in any browser on your phone or computer. There is nothing to download or install.

## Built with
HTML, CSS and JavaScript in a single file, with no libraries. Hosted on Netlify.

## How it was built
I came up with the concept, the learning approach and the design myself. The code was written with AI assistance (Claude).

- How to plan a project, direct an AI tool, test the result and fix problems

## Why I made it
I'm learning German myself and wanted a fun way to practise vocabulary.
